Deploying Your Bot to Production

Follow these steps to host your generated Telegram bot online 24/7.

1 Set Up Telegram Bot Token

Open Telegram, search for @BotFather, send /newbot, follow instructions, and save your HTTP API Token.

2 Local Testing

# Install dependencies

pip install -r requirements.txt

# Run your bot

python main.py

3A Deploy 100% Free on PythonAnywhere (Recommended)

100% Free 24/7
  1. Create a free account on PythonAnywhere.com.
  2. Go to the Files tab and upload your main.py script.
  3. Open a Bash Console from your dashboard and install the library:
    pip install python-telegram-bot
  4. To keep it running 24/7: Go to the Tasks tab, create an Always-on task with:
    python3 main.py
