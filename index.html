Deploying Your Bot to Production

Follow these steps to host your generated Telegram bot online 24/7.

1 Set Up Telegram Bot Token

Open Telegram, search for @BotFather, send /newbot, follow instructions, and save your HTTP API Token.

2 Local Testing

# Install dependencies

pip install -r requirements.txt

# Run your bot

python main.py

3A Deploy 100% Free on PythonAnywhere (Recommended)

100% Free 24/7
  1. Create a free account on PythonAnywhere.com.
  2. Go to the Files tab and upload your main.py script.
  3. In your code, set SENDER_PASSWORD using a 16-character Google App Password (generated via Google Account Security > App Passwords).
  4. Open a Bash Console from your dashboard and install the library:
    pip install python-telegram-bot
  5. To keep it running 24/7: Go to the Tasks tab, create an Always-on task with:
    python3 main.py

3B Deploy on Render.com

  1. Push your code (main.py or bot.js + dependency file) to a GitHub repository.
  2. Create an account on Render.com.
  3. Click New + → Background Worker (Note: Telegram bots require a paid or worker instance to run continuous polling).
  4. Connect your GitHub repository and set Environment Variable:
    BOT_TOKEN = 123456789:ABCdefGHI...

API Key Config

Provide your custom API key (Gemini or Groq) to customize bot code logic. If left blank, the studio uses the built-in fallback key.
