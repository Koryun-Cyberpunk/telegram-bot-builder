Deployment & Hosting Guide

1

Get Bot Token from Telegram

Open Telegram and search for @BotFather. Send the /newbot command, follow instructions, and copy the HTTP API Token provided.

2

Deploying 24/7 Free on Render.com

  1. Create a new repository on GitHub and upload your bot.py and requirements.txt.
  2. Sign up at Render.com and click New + → Background Worker.
  3. Connect your GitHub repo.
  4. Set Start Command: python bot.py (or node bot.js).
  5. Add Environment Variable: BOT_TOKEN with your BotFather token.
  6. Click Create Background Worker. Your bot will run 24/7!
3
