Deploying Your Bot to Production

Follow these steps to host your generated bot online 24/7 for free using Render.com or Railway.

1 Set Up Telegram Bot Token

Open Telegram, search for @BotFather, send /newbot, follow instructions, and save your HTTP API Token.

2 Local Testing

# Install dependencies

pip install -r requirements.txt

# Run your bot

python main.py

3 Deploy 24/7 on Render.com

  1. Push your code (main.py or bot.js + dependency file) to a GitHub repository.
  2. Create a free account on Render.com.
  3. Click New + → Background Worker.
  4. Connect your GitHub repository.
  5. Set Environment Variables:
    BOT_TOKEN = 123456789:ABCdefGHI...
  6. Click Create Background Worker. Your bot will run continuously online!

Gemini API Key Config

Provide your Gemini API key to customize bot code logic using Gemini 2.5/3.0 Flash. If left blank, the studio uses a built-in generator.
